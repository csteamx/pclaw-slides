# 演示截图

幻灯片（`../index.html`）里的截图位按文件名自动加载：放进这个目录、刷新页面就显示；没放的位置显示「截图待补」占位框。
支持 `.png` / `.jpg` / `.jpeg` / `.webp`，文件名（不含扩展名）要和下表一致。

| 文件名           | 截什么                                                         | 用在哪页              |
| ---------------- | -------------------------------------------------------------- | --------------------- |
| `01-product-plan` | 产品「幸运抽签」→ AI 助手：AI 按产品描述规划出的需求列表       | 第 10 页、附录        |
| `02-story-plan`   | 项目 XYC → AI 助手 → 工作项：AI 拆出的用户故事（优先级、故事点、依赖） | 第 11 页左、附录 |
| `03-sprint-plan`  | 项目 XYC → AI 助手 → 迭代：AI 排好的 Sprint（容量、排入的故事） | 第 11 页右、附录      |
| `04-workitem`     | 工作项 → AI 助手页签：上下文条 + 五步步骤条（最好停在审查或 PR 那步） | 第 12 页、附录 |
| `05-review`       | AI 审查结论卡片（必须修改 / 建议修改 / 可以提交）               | 附录                  |
| `06-pr`           | 提交 PR 结果卡片，或 GitHub 上的 PR / 工作项自动变「已完成」    | 附录                  |
| `07-wiki`         | Wiki 里「名单管理」的 AI 研发纪要页面                          | 第 14 页右、附录      |
| `08-lucky-draw`   | 做好的幸运抽签页面（最好是抽中后大字显示的那一刻）             | 附录                  |

建议：浏览器窗口宽一点（≥ 1440），只截页面内容区；截图按原比例放进框里（宽了左右留白、高了上下留白），不会被裁剪。
放映时点击截图可以放大查看，任意键关闭。

## 发布到线上

幻灯片在线地址：https://csteamx.github.io/pclaw-slides/ （公开仓库 `csteamx/pclaw-slides`，GitHub Pages）。
放好截图或改了幻灯片后，在仓库根目录跑 `pnpm slides:publish` 同步上去（会带上 `docs/slides` 里还没提交的改动），一般 1 分钟内生效。
⚠️ 这个地址是公开的，截图里不要带不想公开的数据。
